# TeaSwap TestNet

**git clone script**
```
git clone https://github.com/VEOCE/TEASWAP.git
```
```
cd TEASWAP
```
**Create Screen (opsional)**
```
screen -S teaswap
```
**INSTALL AUTO**
```
chmod +x teaswap.sh
./teaswap.sh
```
**Isi Private key dan alamat token (token telegram boleh kosongin aja)**
```
nano .env
```
**mainkan**
```
node teaswap.js
```
**isi aja swap 60x (itu sama dengan 120x swap)**
# Fungsi tambahan 
**cara masuk screen**
```
screen -r teaswap
```
